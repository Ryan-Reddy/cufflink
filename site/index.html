Reading is easier when you can hear it.

cufflink reads out loud any text you select on Windows and lights up each word as it goes, so your eyes and ears follow together.

In meetings it writes down who said what.

Offline, free, and private.

How to install See the code

Free and open source. For Windows 10 and 11.

How it works

  1. Select some text, in a browser, an email, a document: anywhere.
  2. Press Ctrl + Alt + M. A small window appears straight away with the whole selection in it.
  3. Listen and follow along. Each word lights up as it is read. Words already read stay bright, the rest stay dim.

Pause by clicking the text. Change the speed and the volume, or let it read the same text again until you stop it. Drag the window anywhere on screen; it stays where you leave it.

The keys

Keyboard shortcuts
KeysWhat it does
Ctrl + Alt + MRead the selected text. Press again to read a new selection.
Ctrl + Alt + SpacePause or carry on.
Ctrl + Alt + SStop.
Ctrl + Alt + BSelect mode: everything you select is read straight away.
Ctrl + Alt + ↑ / ↓Faster or slower.
Ctrl + Alt + GGo back to the window you were reading from.
Ctrl + Alt + TOpen the meeting tracker.

Every control also explains itself when you point at it, and the ? button lists them all.

Meetings: who said what

Press Ctrl + Alt + T and the same small window follows a call or a meeting, writing down both sides as text while it happens.

  • Who said what comes from where the sound arrives: your microphone is you, your speakers are everyone else.
  • It starts recording nothing. It listens only while you switch recording on, with Ctrl + Alt + L.
  • Mark a moment with Ctrl + Alt + K, or add a note of your own with Ctrl + Alt + N.
  • When it stops, the text is saved as a file on your computer. The audio is never saved.

Pick who reads to you

Five voices, each with its own character:

  • cufflink: plain and clean.
  • Auntie: the shipping forecast, even and measured.
  • Veronica: offshore radio after dark.
  • Abbey: tape, wound a little slack.
  • The Informant: a recorder in a coat pocket.

Or make your own: blend two speakers, set the speed, and mix the sound with eight dials, from tape flutter to hiss. Hear it plays a sample first; nothing changes until you press Save.

Private by design

  • The speech is made on your own computer. It is not a cloud service.
  • No account, no tracking, no analytics, no ads.
  • The text you select is held in memory only while it is read, then forgotten.
  • Meeting notes are turned into text on your computer and saved there. The audio is not saved and not sent anywhere.
  • Once installed, reading aloud keeps working with the internet switched off. The meeting tracker downloads one more speech model (about 484 MB) the first time you use it, then works offline too.

Install

You need Windows 10 or 11 and about 1 GB of free space. Nothing has to be installed first.

  1. Open the Start menu, type PowerShell and press Enter.
  2. Copy this line, paste it into PowerShell and press Enter:
    irm https://raw.githubusercontent.com/Ryan-Reddy/cufflink/main/install.ps1 | iex
  3. Answer its questions. It asks, for example, whether cufflink should start when you sign in.
  4. Double-click cufflink on your desktop. It sits in the system tray, by the clock, until you need it.

The installer puts cufflink in your user folder, sets up Python if you don't have it, and makes the shortcuts. It downloads the speech models once, about 500 MB, and checks each file before keeping it. It is safe to run again; anything already in place is left alone.

Prefer to do it by hand?

Download the code and double-click Install.cmd:

git clone https://github.com/Ryan-Reddy/cufflink
cd cufflink
.\Install.cmd

For developers

  • A voice for your own apps. While cufflink runs, any program on the same computer can send it text to read, on 127.0.0.1:52719.
  • Hear your Claude Code sessions. A hook in the code says out loud when a session needs you or is done.
  • Open source under the GPL-3.0 licence. The code, the issues and how it is built are on GitHub.
